# KRFS1
Wohnohrtnahe Versorgung in der Metropolregion Stuttgart

Die Ordnerstrukur ist wie folgt aufgebaut:

-data
-docs
-misc
-output
-R
-text

## data
Der Ordner data enthält sämtliche Dateien, welche zur Auswertung notwendig sind. 
Der Unterordner Dummy enthält die Dummydaten, welche vom KR zur Verfügung gestellt wurden.
Hier bitte auch die finalten Daten zur Auswertung ablegen. 

## docs
Dieser Ordner beinhaltet Dokumente wir Präsentationen etc

# misc
Ist eine Sonstige Kategorie

# output
Dieser Ordner enthält sämtlichen von R generierten Output.
Diese werden an den OSP zurückgespiegelt und sollten bezüglich Ihres Outputs kontrolliert werden.

# R
Sämtlicher R-Code ist hier abgelegt.
XX_YY_ZZ_Namensgebend.R ist die allgemeine Struktur der Bennenung, wobei hier von 00 zu 99 aufsteigend gezählt wird.
Ein Styleguide wird versucht einzuhalten.

# text
Sämtliche reine Textnotizen, Lietratur, Quellen dem Projekt zugehörig werden hier hinterlegt.
